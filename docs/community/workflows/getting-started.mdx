Build a `workflow.ts` that replaces deprecated `util.isArray()` and `util.isBuffer()` calls, removes the unused imports, and formats the changed files. You need Node.js, npm, and Git.

## Set up a test project

Create a directory named `my-app`. Run all commands from that directory. Start with these two files:

```ts src/check.ts
import util from "node:util";

export function describe(value: unknown) {
  if (util.isArray(value)) return `list of ${value.length}`;
  if (util.isBuffer(value)) return `${value.length} bytes`;
  return typeof value;
}
```

```ts src/format.ts
import util from "node:util";

export function join(parts: unknown) {
  return util.isArray(parts) ? parts.join(", ") : String(parts);
}
```

## 1. Run a JSSG transform

A [JSSG](/community/jssg) transform receives one file's syntax tree. Create `scripts/util-is.ts` and return an edit plus the number of calls replaced in that file:

```ts scripts/util-is.ts
import type { Codemod } from "codemod/ast-grep";
import type TS from "codemod/ast-grep/langs/typescript";

const REPLACEMENTS = { isArray: "Array", isBuffer: "Buffer" };

const codemod: Codemod<TS> = async (root) => {
  const edits = [];
  for (const [api, global] of Object.entries(REPLACEMENTS)) {
    for (const call of root.root().findAll({ rule: { pattern: `util.${api}($ARG)` } })) {
      edits.push(call.replace(`${global}.${api}(${call.getMatch("ARG")!.text()})`));
    }
  }
  if (edits.length === 0) return null;
  return { edit: root.root().commitEdits(edits), data: edits.length };
};

export default codemod;
```

Create `workflow.ts` at the root. `forEachFile` selects the source files, and `jssg` runs the transform on them in parallel:

```ts workflow.ts
import { forEachFile, jssg, step } from "codemod/workflow";

export default async function main() {
  await step("Replace util.is* calls", forEachFile("src/**/*.ts", jssg("./scripts/util-is.ts")));
}
```

Commit the starting files so the target is clean, then run the workflow and inspect the changes:

```bash
git init
git add .
git commit -m "Before the migration"
npx codemod@2.0.0-alpha.4 workflow run -w ./workflow.ts --target .
git diff -- src
```

You should see two calls change to `Array.isArray` and one to `Buffer.isBuffer`. The imports are still there for now.

## 2. Read data from the transform

`data` can be any JSON value. By default, a JSSG step returns a list of `{ file, data }` entries sorted by file path. Files that returned no data are omitted. Add this in `main` in place of the previous `await step(...)`:

```ts
const migrated = await step(
  "Replace util.is* calls",
  forEachFile("src/**/*.ts", jssg("./scripts/util-is.ts")),
);
const total = migrated.data.reduce((sum, { data }) => sum + Number(data), 0);
console.log(`Replaced ${total} calls`);
```

To try an updated example, restore the original fixture files with `git restore src`. The CLI normally refuses to run on a dirty target, so commit your workflow edits before running again. This example prints `Replaced 3 calls`.

You can also supply an inline reducer to `jssg` to fold the data as files finish, instead of collecting every entry:

```ts
jssg("./scripts/util-is.ts", {
  initial: 0,
  reduce: (sum, { data }) => sum + Number(data),
})
```

With that option, `migrated.data` is the number itself. Unlike the default list, entries reach the reducer in no particular order.

## 3. Run a shell command

A shell step returns `{ stdout, stderr, exitCode }` when it runs. Parse `stdout` to pass a value to the next step. Add `shell` to the `codemod/workflow` import, then append this code inside `main`. Git separates paths with NUL characters so spaces in a filename stay intact:

```ts
const changed = await step("List changed files", shell("git diff --name-only -z -- src"));
const files = changed.stdout?.split("\0").filter(Boolean) ?? [];
if (files.length > 0) {
  await step("Format changed files", shell`npx --yes prettier@3.6.2 --write -- ${files}`);
}
```

The second command uses a tagged template: each array element becomes one quoted argument. In an interactive run, the CLI asks before executing each shell command. A command that exits with an error fails the step unless you pass `{ allowFailure: true }`. A dry run skips shell steps, so `stdout` can be absent.

## 4. Add a decision and a per-file callback

Replace `workflow.ts` with this complete workflow. It returns early when there is nothing to replace, uses a callback to remove the imports left unused in these fixtures, and asks for approval before formatting.

```ts workflow.ts
import { approval, forEachFile, jssg, shell, step } from "codemod/workflow";

const SOURCES = { include: "src/**/*.ts", language: "typescript" } as const;

export default async function main() {
  const migrated = await step(
    "Replace util.is* calls",
    forEachFile(SOURCES, jssg("./scripts/util-is.ts")),
  );

  const total = migrated.data.reduce((sum, { data }) => sum + Number(data), 0);
  if (total === 0) {
    console.log("No util.isArray or util.isBuffer calls found");
    return;
  }
  console.log(`Replaced ${total} calls`);

  const cleaned = await step(
    "Remove unused util imports",
    forEachFile({ ...SOURCES, containing: "node:util" }, (file) => {
      const match = /^import util from "node:util";\r?\n(?:\r?\n)?/m.exec(file.text);
      if (!match) return;
      const withoutImport = file.text.replace(match[0], "");
      if (/\butil\b/.test(withoutImport)) return;
      file.write(withoutImport);
      return file.path;
    }),
  );
  console.log(`Removed the util import from ${cleaned.outputs.length} files`);

  const changed = await step("List changed files", shell("git diff --name-only -z -- src"));
  const files = changed.stdout?.split("\0").filter(Boolean) ?? [];
  if (files.length === 0) return;

  await step(approval(`Format ${files.length} changed files with Prettier?`));
  await step("Format changed files", shell`npx --yes prettier@3.6.2 --write -- ${files}`);
}
```

The callback runs in an isolate for each selected file. `file.write` records an edit, and the callback's returned path goes into `cleaned.outputs`. The workflow passes values between steps directly; it doesn't use shared mutable state.

Restore the fixtures, commit the updated workflow, then run without prompts:

```bash
git restore src
git add workflow.ts
git commit -m "Finish the migration workflow"
npx codemod@2.0.0-alpha.4 workflow run -w ./workflow.ts --target . --no-interactive
```

The run reports `Replaced 3 calls` and `Removed the util import from 2 files`, then pauses at `Format 2 changed files with Prettier?`. Copy the run ID from the output to approve and continue:

```bash
npx codemod@2.0.0-alpha.4 workflow resume --id <run-id> --approve
```

The workflow body runs again, but completed steps reuse their saved results. Inspect `git diff -- src`: both `node:util` imports should be gone. Commit the changes and run the workflow again to see it stop early with `No util.isArray or util.isBuffer calls found`.
