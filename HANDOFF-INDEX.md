# Handoff index

Last updated 2026-11-17 (evening, US Central). One entry per piece of in-flight or recent work, grouped
by project. Each entry gives where the code is, its head commit, the PR it maps to, where it stands,
the decision that waits on Dev, and the branch's own `HANDOFF.md`, which has the full context.

Ground rules for everything listed here:

- `handoff/*` branches are for reading and picking up work. Don't merge them as they are. Where a
  branch's top commit only adds `HANDOFF.md`, drop that commit before moving the code into a PR (each
  doc gives the exact command).
- Nothing listed was published to npm or the Codemod registry, and no new PR was opened.
- Unless noted, commits are authored as Dev Agrawal so the CLA check passes. Exceptions are flagged.
- Copies of every doc also sit in the project's shared folder at `/mnt/project-files/handoff/`.

Repos: `codemod/codemod` (public) is shortened to **cm**, `codemod/codemod-app` (private) to **app**.
Anything with third-party security findings or org-internal data went to **app** on purpose.
